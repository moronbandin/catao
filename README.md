# CATAO

Web de comercio electrónico para una marca gallega de café de especialidad.

## Ejecutar

```bash
npm install
npm run dev
```

Abre la URL que muestra Vite. Para generar una versión de producción:

```bash
npm run build
npm run preview
```

## Incluye

- Inicio, catálogo, fichas de producto, suscripciones, empresas, historia, diario y contacto.
- Carrito persistente en `localStorage`.
- Diseño responsive.
- Selector de idioma GL / ES / EN.
- Catálogo local fácil de sustituir por un CMS.

El checkout incluido es una demostración funcional de interfaz. Para aceptar pagos reales debe conectarse a Stripe, Shopify, Medusa u otro proveedor.
